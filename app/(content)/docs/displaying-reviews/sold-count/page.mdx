# Sold Count

Displays units sold for the current product over a chosen period, e.g. *"120+ sold in the last 7 days"*.

## When to use

Place it near the product title or add-to-cart to signal momentum on fast movers.

## Settings

- **Period** — Last 24 hours / 7 days / 30 days / All time.
- **Text** — your copy, using `{sold_count}` or `{sold_count_compact}` (e.g. `12.9k`). Default: `{sold_count}+ sold in the last 7 days`.
- **Minimum count to show** — hide the block below this number; set to `0` to always show when data exists.
- **Custom CSS** — under advanced settings.

Update the text when you change the period.

## Troubleshooting

- If nothing renders, the count is below **Minimum count to show**, or there is no order data for the period.
