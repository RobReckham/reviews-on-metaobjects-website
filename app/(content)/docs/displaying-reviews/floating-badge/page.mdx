# Floating Badge

A compact store rating badge — inline, or fixed to a corner of the screen as the shopper scrolls.

## When to use

Persistent trust across the whole store, without taking up layout space.

## Settings

- **Colors** — background, text and star colors.
- **Stars** — star size, and optional custom full/empty star icons.
- **Image** — an optional badge image (e.g. a logo).
- **Position** — Inline, or Fixed to bottom-right / bottom-left / top-right / top-left.
- **Link URL** / **Open in new tab** — make the badge clickable.

## Placeholders

`{stars}` `{rating_decimal}` `{max}` `{count}` `{pluralised_reviews}` `{image}` — see the [token reference](/docs/displaying-reviews/customising-app-blocks).

## Troubleshooting

- If it overlaps content, switch **Position** or add `custom_css` offsets.
- If no rating appears, confirm the store has review data.
