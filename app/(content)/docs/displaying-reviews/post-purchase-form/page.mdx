# Post Purchase Form

The post-purchase review form is served as a single native Shopify metaobject page. Email links add `?id=` so the form can load that order's items.

## How it works

When the app sends a review request email, the link points to:

```
https://{your-store}/pages/post-purchase-review-request/submit?id={handle}
```

Every customer lands on the same page. The `id` query param identifies the order. Shopify renders that URL with your theme's **Post-purchase review request** metaobject template, where the **FiveOh Post Purchase Form** block must be present.

The form then loads customer name and ordered items through the app (Liquid cannot read query params). On submission the same `id` is sent back so the app can resolve the original request and mark the review as verified.

Per-order review-request data is stored separately and is not a public storefront page.

## Setup

1. Open the Theme Editor from **App blocks** in the app (**Open in Theme Editor** on Post Purchase Form).
2. Confirm you are on the **Post-purchase review request** metaobject template.
3. Add the **FiveOh Post Purchase Form** section block to that template.
4. Save.

Once the block is on the template, any `{review_link}` the app sends will render your themed form.

## What you can customize

All content and layout is controlled through the block settings in the Theme Editor:

- Heading text
- Star color and size
- Labels and placeholders for rating, title, body, media upload, and author fields
- Submit button text, submitting/submitted states, success and error messages
- Form structure (`structure`, `form_item_structure`) and custom CSS

## Notes

- Place this block only on the **Post-purchase review request** metaobject template.
- The FiveOh Core app embed's **noindex** setting also applies to this page, keeping it out of search results.
- Review link generation is handled automatically by the post-purchase email feature - no manual URL construction needed.

## Troubleshooting

- If the page is blank, confirm the block is added to the **Post-purchase review request** template and saved.
- If the form renders but context is missing (no product names/images), the `id` query param is missing or invalid, or no review request was created for that order.
- If customers report broken links, check that the review request email feature is enabled, `{review_link}` is in the template, and a review request was created for the relevant order.
