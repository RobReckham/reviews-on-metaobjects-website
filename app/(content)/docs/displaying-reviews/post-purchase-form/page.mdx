# Post Purchase Form

The **FiveOh Post Purchase Form** is the page customers land on when they click the link in a [review request email](/docs/collecting-reviews/post-purchase-email). It shows one review form per product of their order, with the product's image and name, so customers review everything they bought in one go. Reviews sent from it are marked as [verified buyer](/docs/managing-reviews/verified-badge) reviews.

## Where to place it

1. Post-purchase review request page

## How it works

Every review request email links to the same page with the order's request ID added:

```text
https://your-store.com/pages/post-purchase-review-request/submit?id=…
```

Shopify renders that URL with your theme's **Post-purchase review request** metaobject template, where the **FiveOh Post Purchase Form** block must be placed. Liquid cannot read the `id` from the URL, so the form loads the customer's first name and the ordered products through the FiveOh script, and sends the same `id` back with every review. That is how FiveOh knows which order a review belongs to.

The page needs the [FiveOh Core](/docs/displaying-reviews/core) app embed, which also keeps it out of search engines.

## Adding it to your theme

1. On the **App Blocks** page in the app, click **Open in Theme Editor** next to Post Purchase Form. This opens the **Post-purchase review request** metaobject template and adds the block.
2. Click **Save**.

From then on, every review link FiveOh sends opens your themed form. To see it, open `https://your-store.com/pages/post-purchase-review-request/submit` without an `id`: it then shows preview products.

## Settings

| Setting | What it does |
|---|---|
| **Star color**, **Star size**, star icons | The look of the rating stars. |
| **Heading tag** | The HTML tag of the heading. |
| **Anchor ID** | An ID for the block. |

When the emails are sent, and what they say, is set in the app, see [Post-purchase email](/docs/collecting-reviews/post-purchase-email).

## Customising

The structure has one `<template data-fo-template="item">` that the script repeats for every product of the order. Change it to change how each product's form looks. The name field sits outside the products and applies to all of them, filled in with the customer's first name.

## Troubleshooting

1. **The page is blank:** the block is missing from the **Post-purchase review request** template, or the theme was not saved.
2. **The form shows no products:** the link has no valid `id`, or no review request was created for the order. Test with the link from a new order.
3. **Customers report broken links:** check that the review request email is turned on and its text contains `{review_link}`.
