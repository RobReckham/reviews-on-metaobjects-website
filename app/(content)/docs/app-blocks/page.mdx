# App blocks

App blocks control how reviews appear across your storefront.

## Placement from the app

In Shopify admin, open **App blocks** in the app and use **Open in Theme Editor** for the app block you want to place.

## Recommended setup order

1. Enable the [FiveOh Core](/docs/app-blocks/core) app embed.
2. Add [Product Rating](/docs/app-blocks/product-rating) and [Review List](/docs/app-blocks/review-list) on product pages.
3. Add [Review Form](/docs/app-blocks/review-form) where customers can submit feedback.
4. Enable [Product Card Ratings](/docs/app-blocks/product-card-ratings) if you want rating hints on listing pages.
5. Enable [Post Purchase Form](/docs/app-blocks/post-purchase-form) if you collect reviews via dedicated links.

## Troubleshooting

- If an app block does not render, confirm it is enabled and saved in Theme Editor.
- If layout looks wrong, verify placement in the correct template and theme section.
- For card and request-page app blocks, check their dedicated docs for required integration steps.
