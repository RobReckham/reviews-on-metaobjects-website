# FiveOh Core

Before placing any section blocks, enable the **FiveOh Core** app embed in the Theme Editor.

It is highly recommended, because it enables a setting to prevent post-purchase review request pages from being indexed by search engines (`Stop review requests from being indexed` - on by default). It is light-weight and will not affect your store's performance.

Enable it under **Theme Editor → App embeds**.
