# Collecting reviews

This page explains the different ways to collect reviews and bring them into your store as native Shopify metaobjects.

**Import from another app**
- [Judge.me](/docs/collecting-reviews/judgeme) · [Loox](/docs/collecting-reviews/loox) · [Reviews.io](/docs/collecting-reviews/reviews-io) · [Trustpilot](/docs/collecting-reviews/trustpilot) · [Shop app](/docs/collecting-reviews/shop-app) · [File import (CSV)](/docs/collecting-reviews/file-import)

**Collect natively with FiveOh**
- [Post-purchase email](/docs/collecting-reviews/post-purchase-email) · [Storefront form](/docs/collecting-reviews/storefront)

You can keep collecting in another app and let FiveOh handle sync and display, collect natively with FiveOh, or run both.

## Troubleshooting

- If data is missing, run a fresh sync/import first.
- If one source fails while others work, troubleshoot that source page directly.
- If data appears in admin but not storefront, verify app block placement and publish settings.
