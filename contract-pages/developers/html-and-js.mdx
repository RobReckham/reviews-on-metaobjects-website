# HTML & JS

Reviews are rendered with Liquid, so they are readable without JavaScript. The FiveOh script, loaded by the [FiveOh Core](/docs/displaying-reviews/core) app embed, only adds interaction: loading more reviews, sorting, filtering, searching, submitting forms and moving sliders. It reacts to the custom elements and `data-fo-*` attributes below, never to CSS classes, so your markup and classes stay entirely yours.

For complete examples, see the [Review List](/docs/displaying-reviews/review-list#examples), [Review Form](/docs/displaying-reviews/review-form#examples) and [Reviews Slider](/docs/displaying-reviews/reviews-slider#examples).
